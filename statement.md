# Project Statement

## Problem Statement

Managing student information manually can be difficult and error-prone. A simple computerized system is needed to store, search, update, delete, and analyze student records.

## Scope

The project covers basic student record management using a Python console application. It stores records in a JSON file and provides CRUD operations and a basic marks report.

## Target Users

- Students learning programming
- Teachers demonstrating basic record management
- Small educational use cases requiring simple student records

## High-Level Features

- Add student
- View students
- Search student
- Update student
- Delete student
- Generate report
- Validate input
- Store records in JSON
- Test important operations
