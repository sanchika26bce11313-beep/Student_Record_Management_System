# Design Decisions and Rationale

## Python
Python was selected because it is the programming language used to implement the project and provides a simple syntax suitable for a beginner project.

## JSON Storage
JSON was selected instead of a database to keep the project simple, portable, and free of external dependencies.

## Modular Structure
The code is divided into interface, business logic, validation, and storage modules to improve maintainability.

## Console Interface
A console interface keeps the project focused on programming concepts rather than graphical design.

## unittest
Python's built-in `unittest` module was selected so that testing can be performed without installing external packages.
